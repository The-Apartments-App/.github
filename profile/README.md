# Apartments App Standards & Definitions

This document outlines core definitions that apply across all Apartments App repositories.

---

## Core Definitions

- **Apartment**: A single building or complex listed in the app.
- **Unit**: An individual rentable space within an Apartment.
- **Tour**: A scheduled viewing session of an Apartment and Unit(s).
- **Application**: A request to rent a Unit.
- **Member**: A user who browses properties, books tours, and provides renter-related information.
- **Manager**: A user who manages properties, updates listings, and oversees tours and unit data.
